Lumio {{VERSION}} for macOS ({{ARCH}})
====================================

1. Drag Lumio onto the Applications folder in this window.

2. This build isn't notarized by Apple yet, so macOS blocks the first launch
   ("Lumio is damaged" or "can't be opened"). Open Terminal, paste this line
   and press Return:

   xattr -dr com.apple.quarantine /Applications/Lumio.app

3. Open Lumio from Applications or Launchpad. You only need step 2 once.

What the command does: it removes the "downloaded from the internet" flag that
macOS puts on files from a browser, so Gatekeeper stops blocking this copy.
It changes nothing else.

Prefer not to use Terminal? Open Lumio once, then go to System Settings >
Privacy & Security, scroll down and click "Open Anyway" next to Lumio.

Lumio updates itself in place, so later versions don't need these steps.
